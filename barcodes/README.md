# Barcodes

Ad-hoc barcode generation. When a barcode is needed for use elsewhere in the
business, ask Claude to create it here.

Not a scheduled process and not part of any pipeline — nothing runs on its own.
It's a working area: the request comes in, the barcode gets made, and whatever
was produced stays here for reference.

## Contents

Reference material kept from previous requests — screenshots of the Amazon
barcode screens (`amazon.png`, `reseterror.png`) and `barcode-actions.docx`,
which records the steps taken.
